# Runbook: 12 Nov 2026 cycle on Colab — 220-member hindcast + 51 real-time members

The bias-corrected AIFS-ENS v2 entry for the 2026-11-12 cycle. The 12 Nov upload window
closes **Sunday 2026-11-15 23:59 UTC**. 5 Nov was the test date (`RUNBOOK_20261105.md`,
paused); the scripts, data sources, credentials rules and measured costs are described there
and in `COLAB_PLAN.md` §9. This file records what was run for 12 Nov.

**271 runs on Colab, one pipeline:**

| Set | Members | Starting states | Stored as |
|---|---|---|---|
| hindcast, 12 Nov 2006–2025 | 20 years × 11 = 220: member 1 = control (ARCO + ecWAM), 2–11 = control + ERA5 EDA perturbation (raw, ×1.0) | `era5_state_pkl.py`, `era5_eda_perturb.py` | `hc-inputs-tmp/1112/<YYYY>/`, products `hc-products/1112/<YYYY>/m<NNN>/` |
| real-time, 12 Nov 2026 00z | 51: members 1–50 = IFS open-data pf, 51 = unperturbed control from HRES 0 h (as the real-time chain) | `s3_grib_pkl_input_aifsens_v2_proto.py` | year **2026** in the same layout: `hc-inputs-tmp/1112/2026/`, `hc-products/1112/2026/m001–m051/` |

All 271 go through the same `hc_member.sh` (792 h rollout, O96 + N320 sidecar, then 3a,
TS days, MJO bands, 10 indices), so hindcast and real-time products come from one extraction
code. **All 15 variables**: the MJO and indices inputs (`vpm_clim_1991_2020.npz`,
`rmm_basis.npz`, `land_sea_mask_1pt5DEG.nc`, from `aifs_20261105_bundle.zip`
`inputs_for_colab/`) are in `colab_aux/` (git-ignored) and `hc_colab.sh push` copies them
to `/content/aux/` on every runtime.

Note: these 51 real-time members are a Colab re-run of the 12 Nov forecast, not the GPU box
run that produced the raw fp16FahamuAIFSv2 submission. Same model and starting states, but a
different draw of the model's noise.

## 1. Commands as run (2026-11-14)

```bash
B=bc-fp16FahamuAIFSv2/colab
# CPU runtime: code, keys, aux files, packages, wave mask
$B/hc_colab.sh up hcA cpu; $B/hc_colab.sh push hcA; $B/hc_colab.sh creds hcA
$B/hc_colab.sh sh hcA 'uv pip install --system -q earthkit-regrid==0.5.1 eccodes gribberish obstore ecmwf-api-client boto3 zarr fsspec aiohttp requests'
#   + earthkit matrix warm-up and ref_wave_land_n320.npy from the 20261029 open-data member 1
#     (RUNBOOK_20261105 section 4.1); land 0.3029
$B/hc_colab.sh realtime hcA 20261112 4                       # log /content/realtime_20261112.log
#   hindcast chain, /content/hc1112.sh, log /content/phaseA_1112.log:
#     hc_phaseA.py --mmdd 1112 --years 2025-2006 --jobs 4
#     hc_phaseA.py --mmdd 1112 --years 2025-2006 --jobs 2 --perturbed 2-11 --inflate 1.0

# GPU: 3 L4 runtimes (a 4th was not granted)
for n in hcB hcC hcD; do
  $B/hc_colab.sh up $n L4; $B/hc_colab.sh push $n; $B/hc_colab.sh creds $n; $B/hc_colab.sh setup $n
  $B/hc_colab.sh worker $n 1112 --wait 10800                 # log /content/worker_1112.log
done
# credentials: a loop on the gateway re-runs `hc_colab.sh creds` on every live runtime
# every 5 min (source.coop S3 credentials last <= 12 h; workers re-read /root/.sc.env)
```

Expected: Phase A ~2–3 h (CDS-bound); B 271 × ~8.5 min / 3 runtimes ≈ 13 h, ~79 CU.

## 2. Problems hit and fixes

| Problem | Fix |
|---|---|
| **Colab ended the CPU runtime after ~24 h** (2026-11-15 ~15:35 UTC, the Pro runtime lifetime): ERA5 weekly truth, index truth (~120 CDS requests), IBTrACS and the half-built bundle were only on its disk and were lost | new runtime; every product now goes to source.coop as soon as it is made (`hc-products/1112/truth/`, `bundle_1112.zip`, `bc_out/`); index truth not refetched before the deadline (only indices 6–15 need it, not submitted); `hc_bc15.py` runs TS/MJO without it |
| the three L4s sat idle overnight after the last member (~45 CU) | the watch had expired; stop GPU runtimes as soon as the DONE count is complete |
| `colab ssh` creates a runtime when the named one is gone | `hc_colab.sh` refuses to connect unless the session exists |
| 2022 control build: `sqlite3.OperationalError: database is locked` (earthkit cache, 8 processes starting together) | `hc_phaseA.py` retries a build up to 3 times; the perturbed step skips a year whose control is not on source.coop yet (rerun picks it up) |
