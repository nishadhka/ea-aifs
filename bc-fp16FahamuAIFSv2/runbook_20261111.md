# Runbook 2026-11-11: same-date hindcast for 5 Nov and AIFS-ENS v2 inference from ERA5

How the 5 Nov hindcast was built and run between 2026-11-09 and 2026-11-10, on this box,
with the scripts, commands, data volumes and timings as measured. Use it to repeat the run
for another date or to extend it to 220 members.

## 0. What was run, and what was not

| | Status |
|---|---|
| **Control hindcast, 5 Nov 2006–2025** | **Done.** 20 members, one ERA5-started run per year, 792 h each |
| 220 members (20 years × 11: control + 10 ERA5 EDA perturbations) | **Not run.** CDS access to the EDA members is tested and works; the code that turns EDA members into perturbed starting states is **not written yet** (§9) |
| Gate: does an ERA5 start behave like an IFS start at weeks 3–4? | Done, passes (§7) |
| Bias correction of the 20261105 forecast from the hindcast | Done: `aifs-run/20261105_0000/aiwq_bc_hc/ensemble_quintile_probabilities_20261105_bchc.nc` (not submitted) |

So every number below is for the **20-member control hindcast**. The starting states use
**ERA5 (ARCO) + the ecWAM wave hindcast (MARS)**. **CDS supplied no data to any starting
state yet**, only a 5.2 MB access test.

## 1. Pipeline

```
for each year Y in 2006..2025, date D = Y-11-05 00 UTC
  1  era5_state_pkl.py      ARCO-ERA5 (100 fields)  ─┐
                            MARS ecWAM (12 wave fields) ─┴─> input_state_member_001.pkl (971 MB)
  2  hc_member.sh           run_local_icechunk_v2.py  792 h rollout, N320 sidecar 2t/msl/tp 432-792 h
                            aifs_n320_grib_1p5defg_nc_cli.py  regrid to 1.5 deg (3a)
                            delete both stores -> keep one 1.5 deg NetCDF (41 MB on disk)
     hc_date.sh             runs step 2 for every year whose pkl exists; deletes the pkl after
  3  hc_bc.py obs           ERA5 weekly tas/mslp/pr for D+18 d and D+25 d (era5_weekly.py)
  4  hc_bc.py evaluate      leave-one-year-out test of the bias correction
  5  hc_bc.py apply         correct the 51-member 20261105 real-time forecast
```

## 3. Starting state (pkl) from ERA5 + waves

Script: **`bc-fp16FahamuAIFSv2/era5_state_pkl.py`**. Output:
`dict(date=datetime, fields={name: float64 (2, 542080)}, source=...)` for [t−6 h, t],
the format `run_local_icechunk_v2.py` reads, with the same 112 field names as the IFS
open-data builder (`s3_grib_pkl_input_aifsens_v2_proto.expected_field_names()`).

| Group | Fields | Source | Transform |
|---|---|---|---|
| Surface | `10u 10v 2d 2t msl skt sp tcw sd` | ARCO | 0.25° → N320 with the IFS builder's own `to_n320` (earthkit-regrid, linear) |
| Soil | `stl1 stl2 swvl1 swvl2` | ARCO | as above |
| Constants | `lsm z slor sdor` | ARCO (ERA5's own, what the model was pretrained on) | as above |
| Pressure levels | `z t u v w` × 14 levels, `q` × 13 (no `q_10`) | ARCO, levels 1000…10 hPa | as above. ERA5 `geopotential` is already m² s⁻² (the IFS route multiplies gh by g) |
| Waves | `h1012 h1214 h1417 h1721 h2125 h2530 swh mwp cdww wmb` + `cos_mwd sin_mwd` | MARS ecWAM Cy50r1 forced by ERA5 (the wave hindcast AIFS was trained on), `grid=N320` | `mwd` → cos/sin; land mask aligned to the operational one (30.3 % land) with `fetch_j1r2.reconcile_mask` against `/tank/projects/bc-aifs/ref_wave_land_n320.npy` (saved from the 20261029 IFS pkl) |
| Sea masking | `sd swvl1 swvl2` | — | NaN where N320 `lsm == 0`, exactly as the IFS builder |

Measured per state: ARCO fetch 410–470 s, regrid 3–5 s, MARS waves seconds when on disk
(tape: up to several hours), pkl 971 MB.

Checks done:
- **20261029 vs that day's 10 IFS members** (waves copied from the IFS pkl, to test the ARCO
  part alone): atmosphere fields differ by 1.0–2.4 IFS ensemble spreads, as expected
  between two analyses. The larger gaps have physical causes: `sp` follows ERA5's coarser
  orography, `q_50` is ERA5's moist stratosphere, soil comes from a different land
  analysis, and `sd` differs on ~2 000 glacier-edge points (ERA5's glacier mask).
  There are no unit, level or sign errors.
- **20251105** (waves from `itul`): 112/112 fields, wave land fraction 0.303 (operational
  0.303), no unexpected NaN, values physical.

## 4. Inference

| | |
|---|---|
| Model | `ecmwf/aifs-ens-2.0` from Hugging Face, via `anemoi.inference.runners.simple.SimpleRunner`, device `cuda`, precision **FP16**, 16 inference chunks |
| Hardware | NVIDIA RTX 5000 Ada Generation, 30.7 GB |
| Environment | `/tank/projects/micromamba/envs/aifs-gpu`: anemoi-inference 0.8.3, anemoi-models 0.11.2, torch 2.7.0, flash-attn 2.7.4.post1, earthkit-regrid 0.5.1, icechunk 2.1.0, zarr 3.2.1, xarray 2026.4.0, ecmwf-api-client 1.7.0, AI_WQ_package 3.29 |
| Env vars | `HF_HOME=/tank/projects/hf_cache` (not `hf_home`) |
| Run script | `fp16FahamuAIFSv2/run_local_icechunk_v2.py` (unchanged) |
| Lead, step | 792 h = 132 steps of 6 h |
| What is stored | O96 store: one step (792 h), because the script needs a main store. N320 sidecar: `msl, tp, 2t` for 432–792 h (61 steps), which is the window 3a reads |
| Time per member | rollout **200.6 s** (1.5 s per step) + model load ~1 s + 3a regrid 11 s ≈ **3.6 min** |
| Disk per member | temporary stores 249 MB (N320) + 17 MB (O96), deleted after 3a; kept: 1.5° NetCDF 200 MB apparent / **41 MB on zfs** |
| 20 members | 20 × 3.6 min ≈ 72 min of GPU. Wall time was set by the state builds (ARCO ~7 min each) and MARS tape |

The per-member command, as `hc_member.sh` runs it:

```bash
export HF_HOME=/tank/projects/hf_cache
cd /home/ezra/ea-aifs/fp16FahamuAIFSv2
$PY -u run_local_icechunk_v2.py --date $DT --members 1 --n-members 1 --lead-time 792 \
    --input-dir $STATE \
    --grid o96 --store $WORK/icechunk_o96 --write-hours 792-792 \
    --native-store $WORK/icechunk_n320 --native-vars msl,tp,2t \
    --native-write-hours 432-792 --commit-every 1 --float-size f4
$PY -u ../shared/aifs_n320_grib_1p5defg_nc_cli.py --date $DT --members 1 --v2 \
    --no-upload --source icechunk --icechunk-store $WORK/icechunk_n320 \
    --source-grid n320 --icechunk-tag cycle-$DT --output-dir $OUT
```

## 5. Post-processing and bias correction

| Step | Script | Detail |
|---|---|---|
| Weekly aggregation | `past_cycle_bc.py` (`aggregate`, also called from `hc_bc.py`) | Exactly 3b's aggregation: week 3 = time chunks 0,1 (24 steps), week 4 = chunks 2,3,4 (36 steps); tas/msl step means, tp sum × 1000 × 7/days. Float64: reproduces 3b's 20261105 submission file in every cell |
| ERA5 truth | `era5_weekly.py` | tas, mslp: mean of 6-hourly 00/06/12/18 UTC from D 00 to D+6 18; pr: hourly tp sum from D 01 to D+7 00, × 1000; every 6th 0.25° point |
| Bias fit | `hc_bc.py` (`fit_table`) | tas, mslp additive, pr ratio (limited to ⅓–3). Chosen setting `sig_a0.5`: unsmoothed 20-year bias, kept only where it is significant (two-sided t-test, p < 0.05; pr tested on log ratio), applied at half strength |
| Probabilities | `past_cycle_bc.quintile_probs` | 3b's lower-closed bins against the AI-WQ 20-yr quintile edges |

## 6. Commands as run (in order)

```bash
PY=/tank/projects/micromamba/envs/aifs-gpu/bin/python
cd /home/ezra/ea-aifs/bc-fp16FahamuAIFSv2
S=/tank/projects/bc-aifs

# 0. reference wave land mask (once), from an IFS pkl
$PY -c "import pickle,numpy as np; f=pickle.load(open('/tank/projects/aifs-run/20261029_0000/input_states/input_state_member_001.pkl','rb'))['fields']; np.save('$S/ref_wave_land_n320.npy', ~np.isfinite(f['swh'][1]))"

# 1. check the ARCO part against IFS (waves borrowed from the IFS pkl)
I=/tank/projects/aifs-run/20261029_0000/input_states
$PY -u era5_state_pkl.py --date 20261029_0000 --out $S/era5_states/20261029_0000_check \
    --waves-from $I/input_state_member_001.pkl --compare-ifs $I

# 2. wave files ahead of the builder, oldest first (tape waits overlap)
$PY -u prefetch_waves.py 1105 2006 2022

# 3. starting states, 3 tries per year, ARCO cache removed after each pkl
for y in $(seq 2006 2025); do D=${y}1105_0000
  for try in 1 2 3; do $PY -u era5_state_pkl.py --date $D --out $S/era5_states/$D && break; sleep 120; done
  rm -f $S/arco_states/$D.npz
done

# 4. members, as states appear (runs in parallel with step 3)
./hc_date.sh 1105 2006 2025 > $S/hc_1105.log 2>&1

# 5. gate: ERA5-started 20261029 member vs the 50 IFS members
./hc_member.sh 20261029_0000 $S/era5_states/20261029_0000_check $S/hc_nc/20261029_0000_era5check
#    (comparison script: rank and distance against /tank/projects/bc-aifs/weekly/20261029.npz)

# 6. verification, evaluation, correction of the real-time forecast
$PY -u hc_bc.py obs 1105 2006 2025
$PY -u hc_bc.py evaluate 1105 2006 2025
$PY -u hc_bc.py apply --date 20261105 --setting sig_a0.5
```

## 7. Results

**Gate (study plan §2.4, S2S form).** ERA5-started 20261029 member against that day's 50
IFS members, weeks 3–4: bias ≤ 0.05 ensemble spread for tas, mslp and pr; distance from
the ensemble mean 0.91–1.19× a typical IFS member; flat rank histogram (0.14–0.25 per
quintile). Starting from ERA5 makes no measurable difference at these leads.

**Leave-one-year-out MSE change, `sig_a0.5`** (40 cases = 20 years × 2 weeks):

| | Global (land for tas/pr) | Greater Horn of Africa land | Cases improved global / GHA |
|---|---|---|---|
| tas | −2.7 % | −5.7 % | 36/40 / 30/40 |
| mslp | +0.0 % | −16.7 % | 26/40 / 31/40 |
| pr | −2.6 % | −10.0 % | 35/40 / 37/40 |

GHA biases at weeks 3–4: mslp +0.8–0.9 hPa (significant on ~2/3 of the region), tas
−0.15/−0.37 K, pr −3.9/−1.4 mm per week. Largest corrections are over the Tibetan
Plateau (tas up to +13 K, mslp about −14 hPa), partly the forecast/ERA5 mismatch over
high ground. The earlier past-cycle tables barely match the 20-year bias (pattern r
−0.18 to +0.29) and are superseded.

The corrected 20261105 file changes the modal quintile in 3–4 % of cells (past-cycle
file: 20–24 %). It passes `prepare_aiwq_submission`. It has not been submitted.

## 10. Problems hit and fixes

| Problem | Fix |
|---|---|
| `j5rf` has no data after September 2026 | 2026 check used the IFS pkl's waves (`--waves-from`) |
| earthkit-regrid "No matrix found" when 8 threads load the matrix at once | one regrid call before the thread pool |
| Wave mask passed as (542080,) where (2, 542080) was expected | broadcast to the state shape |
| A MARS request waited 3 h on tape and stalled every later year | `prefetch_waves.py` in the opposite year order |
| `hc_date.sh` waited 1 h per year in fixed order and skipped 2023 and 2022 | runs any ready year, stops after 6 h idle |
| Network outage 2026-11-10 ~03:40–14:00 UTC (DNS failures for GCS and ECMWF) | 3 retries per state; restart picked up where it stopped |
| AI-WQ obs folder ends at 20260824; failed FTP leaves 0-byte files | `era5_weekly.py`; 0-byte files deleted |
